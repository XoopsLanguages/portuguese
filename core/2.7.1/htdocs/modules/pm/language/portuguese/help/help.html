DESCRIÇÃO

O módulo PM é para mensagens privadas entre usuários

INSTALAR/DESINSTALAR

Não são necessárias medidas especiais, siga o processo de instalação padrão – extraia a pasta /pm para o diretório ../modules. Instale o módulo através de Admin -> Módulo do Sistema -> Módulos.

Instruções detalhadas sobre a instalação dos módulos estão disponíveis no Os campos Operações XOOPS Manuais

INSTRUÇÕES DE OPERAÇÃO

Para configurar este módulo você precisa:

  • Você entra na sua Caixa de Entrada diretamente na página inicial, ou clicando no link superior “Ir para o módulo” na área Admin do PM.
  • Configure suas preferências para o módulo (veja “Preferências”) e opcionalmente o bloco PM caso pretenda utilizá-lo (veja “Blocos”).
  • Você pode excluir em massa suas mensagens usando a guia “Remover” Mensagens.
