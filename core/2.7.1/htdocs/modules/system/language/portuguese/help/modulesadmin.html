Ajuda: Módulos

Descrição

Módulos são construções de software que, aproveitando a infraestrutura que o XOOPS oferece, permitem ao webmaster oferecer aos usuários do site conteúdo dinâmico ou estático gerado através de uma interface Web que na maioria das vezes é muito fácil de usar.

Parte do poder do XOOPS reside na forma como os módulos são gerenciados. O webmaster pode facilmente instalar, desinstalar, ativar ou desativar qualquer módulo específico (exceto o módulo Sistema, por motivos óbvios). Também é possível renomear módulos e determinar a ordem em que eles serão aparecem para o usuário final no menu do site (se você quiser que apareçam), pois você também pode fornecer funcionalidades ocultas, definindo módulos ativos que não têm presença visível para o usuário casual. Por exemplo, você pode definir um módulo como não visível no menu desabilitando a opção ícone de verificação na coluna Menu. Portanto, para o módulo Notícias, você pode enviar mensagens privadas para um grupo selecionado de seus usuários e solicitar que eles acessem esse diretório digitando o endereço no campo URL, algo como http://www.yoursite.com/modules/news.

Para alterar a ordem dos módulos (que será refletida no Menu), basta arrastar e soltar os módulos no posicionamento desejado. O link

A instalação dos módulos necessita de algum planejamento, tanto nos módulos a serem exibidos quanto no layout das páginas. É uma boa ideia revisar outros sites XOOPS e ver quais módulos são usados ​​para exibir vários tipos de conteúdo. Isso é feito facilmente abrindo qualquer site XOOPS e passando o mouse sobre os links do menu nos painéis laterais esquerdo e direito. Ao mesmo tempo, observe os URLs exibidos na barra de status do seu navegador. Você deverá ver endereços como este: http://the_site.com/modules/news/.... Todos os módulos são armazenados no diretório /modules/, portanto o seguinte setor do endereço (neste exemplo 'notícias') mostra o módulo que exibirá o conteúdo desse link de menu.

Se você abrir a página do link, ele mostrará um exemplo de como o módulo é usado e o tipo de conteúdo que ele exibe. A revisão de outros sites como este também lhe dará uma boa visão dos recursos de layout e design.
