Ajuda: Usuários de e-mail

Descrição

XOOPS possui um sistema de mensagens integrado que permite enviar uma mensagem para toda a sua base de usuários registrados ou subgrupos deles, ou usando filtros de data. Isso pode ser na forma de uma mensagem privada (ou seja, por meio do sistema de mensagens integrado do XOOPS) ou por e-mail. Uma gama de opções é disponível para filtrar subgrupos de usuários de sua associação.

Você também pode usar tags predefinidas que permitirão personalizar sua mensagem.
