Instalando o XOOPS

Primeira instalação

Prefácio:

XOOPS é um código aberto Sistema de publicação na Web orientado a objetos escrito em PHP. É uma ferramenta ideal para desenvolvendo sites comunitários dinâmicos de pequeno a grande porte, portais intraempresas, portais corporativos, weblogs e muito mais.

XOOPS é lançado sob os termos do Licença Pública Geral GNU (GPL) versão 2 ou superior e é gratuito para usar e modificar. A redistribuição é gratuita, desde que você cumpra os termos de distribuição da GPL.

Requisitos

  • Servidor WWW (Apache, NGINX, IIS, etc.)
  • PHP 8.2 ou superior, 8.4+ recomendado
  • MySQL 5.7 .8 ou superior, MySQL 8.4.5+ recomendado

Antes de instalar

  1. Configure o servidor WWW, PHP e servidor de banco de dados corretamente.
  2. Prepare um banco de dados para seu site XOOPS.
  3. Prepare a conta do usuário e conceda ao usuário acesso ao banco de dados.
  4. Torne os diretórios e os arquivos graváveis: %s
  5. Por questões de segurança, é altamente recomendável mover os dois diretórios abaixo para fora do raiz do documento e altere os nomes das pastas: %s
  6. Crie (se ainda não estiver presente) e torne os diretórios graváveis: %s
  7. Ative o cookie e o JavaScript do seu navegador.

Instalando localmente

Se você estiver executando um ambiente local para desenvolvimento ou teste, certifique-se de ter o anterior requisitos atendidos. Feito isso, copie o conteúdo do htdocs (do XOOPS arquivo de distribuição) para o caminho do documento raiz do seu ambiente web. Depois que os arquivos forem copiados para lá, você pode iniciar a instalação apontando seu navegador para "http://seusite.com". Isso iniciará o processo de instalação.

Instalando em uma plataforma hospedada

Se você estiver executando em um ambiente hospedado, descompacte os arquivos XOOPS localmente ou no servidor, se tiver acesso shell (ou seja, SSH). Uma vez feito isso, certifique-se de mover ou copiar todos os arquivos XOOPS do htdocs para o diretório raiz da web (seu provedor geralmente fornece instruções para esse local). Depois que os arquivos forem copiados lá, você pode iniciar a instalação apontando seu navegador para "http://seusite.com". Isso iniciará o processo de instalação.
