DESCRIÇÃO

O módulo Perfil serve para gerenciar campos personalizados de perfil de usuário.

INSTALAR/DESINSTALAR

Não são necessárias medidas especiais, siga o processo de instalação padrão – extraia a pasta /profile para o diretório ../modules. Instale o módulo através de Admin -> Módulo do Sistema -> Módulos.

Instruções detalhadas sobre a instalação dos módulos estão disponíveis no Os campos Manual de Operações XOOPS

INSTRUÇÕES DE OPERAÇÃO

Para configurar este módulo você precisa:

  • Configure suas preferências para o módulo (veja ‘Preferências’) e opcionalmente o bloco Perfil se você pretende usá-lo (veja ‘Blocos’).
  • Edite categorias existentes ou adicione novas.
  • Edite campos existentes ou adicione novos. Aqui você pode especificar quais campos ficarão visíveis em qual categoria e se ficarão visíveis durante o registro do usuário.
  • Defina a ordem das etapas de registro.
  • E finalmente, você pode definir permissões para campos individuais - quais são editáveis, quais são pesquisáveis.

Medidas antispam

Para minimizar registros de spam, faça o seguinte:

  • vá no módulo Protector no Admin, vá em Preferências, e depois na parte inferior, nesta opção: "Parar spam no fórum" Verifica os dados do POST contra spammers registrados no banco de dados www.stopforumspam.com.
    Defina como "Banir o IP (sem limite)"

  • em /class/captcha/config.php, certifique-se de que o modo esteja definido como "texto":

    return $config = array(
    'disabled' => false, // Desativa CAPTCHA
    'mode' => 'text', // modo padrão, você pode escolher 'text', 'image', 'recaptcha'(requer chave de API)
    'nome' => 'xoopscaptcha', // nome do captcha
    'skipmember' => true, // Pular verificação de CAPTCHA para membros
    'maxattempts' => 10, // Máximo de tentativas para cada sessão
    );

  • No módulo Perfil, vá para Admin e na etapa Básica localizada em:
    /modules/profile/admin/step.php?id=1
    defina "Salvar após parar" como "Não"


  • Nas Preferências do Perfil, defina a opção "Usar Captcha após a segunda etapa de registro" como "Sim" (é o padrão)
