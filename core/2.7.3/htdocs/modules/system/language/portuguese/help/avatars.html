Ajuda: Avatar

Descrição

Avatares são pequenos gráficos ou imagens que podem ser usados ​​em diversas configurações de conteúdo do site. Eles costumam ser usados ​​ao lado de um nome de usuário para adicionar um pouco de “identificação visual”. As aplicações típicas são o fórum.

O Gerenciador de Avatar permite que o administrador do Site adicione, edite ou exclua Avatares do Sistema, bem como Avatares Personalizados.

Avatar do Sistema

Avatares do Sistema são imagens enviadas pelo administrador do Site na seção Gerenciador de Avatares.

Avatar personalizado

Avatares personalizados são imagens enviadas diretamente por um usuário. Para que um usuário possa fazer upload de um avatar, a opção correta deve ser configurada nas Configurações de informações do usuário nas Preferências do site.

Editar e excluir avatares

O administrador do Site pode editar o nome e a ordem de exibição de todos os Avatares do Sistema, bem como excluir qualquer um deles. Observe que se o administrador do Site excluir um avatar que um usuário esteja usando, esse usuário perderá seu avatar.
