Bem-vindo à: Central de ajuda do XOOPS

Como uso o XOOPS?

XOOPS é uma plataforma de aplicação web escrita em PHP para o banco de dados MySQL. Sua orientação a objetos o torna uma ferramenta ideal para o desenvolvimento de sites comunitários de pequeno ou grande porte, portais intraempresariais e corporativos, weblogs e muito mais. Para usar o XOOPS de forma eficaz, você precisa instale módulos que forneçam a funcionalidade que você procura. Existem muitos módulos diferentes em Repositório de Módulos, desde calendários, galerias de fotos, passando por notícias, quadros de avisos, até atualizações meteorológicas.

Como posso usar a Central de Ajuda?

A Central de Ajuda fornece informações básicas relacionadas aos recursos individuais da Administração. Sempre que você quiser saber mais sobre uma determinada página em que está, basta clicar no ícone de ajuda no canto direito

Como posso criar conteúdo no XOOPS?

Você precisará de um módulo para isso. Este pode ser um módulo de Notícias ou um módulo de Conteúdo.
