Ajuda: Manutenção

Descrição

Manutenção fornece várias funções básicas para ajudá-lo a manter sua instalação XOOPS e mantê-la saudável:

- limpar pasta de cache
- esvazia a tabela de sessão
- realizar manutenção das tabelas do banco de dados (analisar, verificar, otimizar e reparar)

Você também pode realizar um "Dump" de todo o banco de dados ou de tabelas individuais para fins de backup.
