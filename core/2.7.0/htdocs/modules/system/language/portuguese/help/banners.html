Ajuda: Banners

Descrição

Banners são anúncios exibidos na seção superior da página. Podem ser imagens ou filmes em flash, por ex. o banner XOOPS girando descontroladamente que faz parte da instalação padrão. O XOOPS possui um sistema integrado para gerenciamento de banners e criação de contas para clientes publicitários, que é encontrado no Módulo do Sistema -> Banners. Você pode ter vários banners em um site XOOPS – a área de exibição gira através de cada um dos banners ativos cada vez que uma nova página é carregada.

Cada vez que um banner é exibido para um visitante, isso conta como uma ‘impressão’, que é a moeda comercial comum dos banners. Os clientes normalmente pagam por um determinado número de impressões – ou seja, para que seu anúncio seja exibido um determinado número de vezes.

Atenção: Se você vende banners com base no número de impressões, há uma coisa importante que você deve fazer: Vá para Módulo do Sistema -> Preferências -> Configurações Gerais e preencha o campo ‘Seu endereço IP’ (se você tiver um). Isto impedirá que você visite o site seja incluído na contagem de impressões. Não fazer isso pode ser considerado um tanto desonesto (observando, no entanto, que muitos administradores não têm um IP permanente – por exemplo, aqueles que usam modems dial-up).
